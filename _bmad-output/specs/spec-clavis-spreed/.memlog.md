- (constraint) Fork discipline: clavis-spreed tracks upstream Talk stable34/24.0.3; no plugin extension point exists for thread semantics, so upstream files are edited directly, minimally, and marked. git fetch --unshallow is a prerequisite of the first commit.

- (constraint) Two capability flags (thread management, unread semantics), each in BOTH FEATURES and LOCAL_FEATURES — features-local is the only channel that tells a client a feature does not work over federation.
- (constraint) Every Thread mutation invalidates the 900s distributed cache entry with remove(), never set(). Only the read path repopulates. Highest-risk correctness surface.
- (constraint) Single-seam rule: ThreadService is the sole write seam for thread rows; ChatManager is the sole write-policy seam for posted content; useChatExtrasStore is the sole client owner.
- (constraint) Scale target >=1000 Threads and 200 participants per Conversation; no per-request work proportional to Thread count; fixed queries per page; keyset cursor on (featured, last_activity desc, id desc); client never re-sorts.

- (constraint) Thread Titles and Thread Tags carry message-grade sensitivity: withheld wherever the sensitive-conversation setting already withholds previews, and never in any push-envelope part the Clavis push proxy can read.
- (constraint) Federation degrades by omission — affordances hidden, never rendered inert; no new Thread field or endpoint proxied.
- (constraint) Concurrency: last write wins, no conflict token; the mutation response is the correction and the client replaces its copy with it.
- (constraint) CI runs four DB engines including Oracle; normalisation, grouped queries and migrations must hold on all four.
- (constraint) Accessibility/theme/localisation: state never conveyed by colour alone, bounded palette from host design tokens, keyboard reachable, both themes; Vietnamese correctness in search matching, truncation and sorting.
- (constraint) PRD §3 glossary is binding vocabulary; a synonym anywhere downstream is a defect. Featured (not pinned), Thread Tag (not label) — both avoid collisions with shipped Talk features.
